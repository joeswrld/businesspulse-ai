📋 Embed Code

Copy this code to embed the feedback widget on your website:

<script> (function() { var script = document.createElement('script'); script.src = 'https://your-domain.com/feedback-widget.js'; script.setAttribute('data-project-id', 'your-project-id'); script.setAttribute('data-widget-color', '#3B82F6'); script.setAttribute('data-widget-title', 'Share your feedback with us!'); script.setAttribute('data-greeting-text', 'Welcome, tell us what\'s on your mind'); document.head.appendChild(script); })(); </script>

⚙️ Configuration

The feedback system can be customized through the database settings:

  • Widget Color: Set in feedback_settings.widget_color
  • Widget Title: Set in feedback_settings.widget_title
  • Greeting Text: Set in feedback_settings.greeting_text
  • Form Types: CSAT, Product Feedback, or Both
