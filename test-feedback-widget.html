🔧 NoteX Feedback Widget Test Page

📋 Test Instructions

  1. Replace YOUR_PROJECT_ID in the script tag below with your actual project ID
  2. Make sure your NoteX platform is running and accessible
  3. Configure your feedback settings in the NoteX dashboard
  4. Test the widget by clicking the feedback button (should appear in bottom-right)
  5. Submit both satisfaction and product feedback forms
  6. Check the feedback dashboard to verify submissions

🚀 Widget Integration

Add this script tag to your website to enable the feedback widget:

<script src="http://localhost:5173/widget.js" data-project-id="YOUR_PROJECT_ID"></script>

Note: Replace YOUR_PROJECT_ID with your actual project ID from the NoteX dashboard.
