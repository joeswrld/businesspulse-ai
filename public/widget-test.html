NoteX Feedback Widget Test

This page demonstrates the NoteX feedback widget in action. You should see a floating feedback button in the bottom-right corner of the screen.

Note: This is a test page. The widget will only work if you have a valid project ID and the Supabase configuration is properly set up.

How to use the widget:

  1. Click the floating feedback button (bottom-right corner)
  2. Fill out the feedback form
  3. Submit your feedback

Embed Code:

<script src="https://notex.com.ng/widget.js" data-project-id="YOUR_PROJECT_ID"></script>

Replace YOUR_PROJECT_ID with your actual project ID from the NoteX dashboard.

Features:

  • ✅ Lightweight and fast loading
  • ✅ Responsive design
  • ✅ Customizable colors and text
  • ✅ Email collection (optional)
