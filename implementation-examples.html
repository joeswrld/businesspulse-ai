Multi-Channel Feedback Implementation Examples

1. Website Widget Integration

Add this to your website where the feedback widget should appear:

<!-- Include the feedback API -->
<script type="module" src="./feedback-api.js"></script>

<!-- Your existing widget HTML -->
<div id="feedback-widget">
    <form id="widget-feedback-form">
        <input type="text" name="name" placeholder="Your name (optional)">
        <input type="email" name="email" placeholder="Your email (optional)">
        <textarea name="message" placeholder="Your feedback" required></textarea>
        <button type="submit">Submit Feedback</button>
    </form>
</div>

<script>
// Wire up the form
import { handleFeedbackForm } from './feedback-api.js';
document.addEventListener('DOMContentLoaded', () => {
    const form = document.getElementById('widget-feedback-form');
    handleFeedbackForm(form, 'widget');
});
</script>

4. Direct API Usage

If you prefer to handle form submission manually:

import { submitWidgetFeedback, submitQRFeedback, submitEmailSignatureFeedback } from './feedback-api.js';

// For widget
const result = await submitWidgetFeedback({
    name: 'John Doe',
    email: 'john@example.com',
    message: 'Great product!'
});

// For QR code
const result = await submitQRFeedback({
    name: 'Jane Smith',
    email: 'jane@example.com',
    message: 'Could use better documentation'
});

// For email signature
const result = await submitEmailSignatureFeedback({
    name: 'Bob Wilson',
    email: 'bob@example.com',
    message: 'Love the new features!'
});

if (result.success) {
    console.log('Feedback submitted:', result.data);
} else {
    console.error('Error:', result.error);
}

5. Environment Variables

Create a .env file in your project root:

VITE_SUPABASE_URL=your-supabase-project-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key

Or set them directly in your code:

// In feedback-api.js, replace these lines:
const supabaseUrl = 'https://your-project.supabase.co';
const supabaseKey = 'your-anon-key-here';
