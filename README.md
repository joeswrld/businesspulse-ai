# 🚀 NoteX — Real-Time AI Feedback Intelligence

NoteX is an AI-powered feedback and insights platform that helps product teams **capture, analyze, and act on user feedback in real time** — without noise, delay, or guesswork.

If users are talking, NoteX is listening.

---

## 🧠 What Problem NoteX Solves

Most teams collect feedback.
Very few *understand it* fast enough to act.

The result?

* Missed product signals
* Slow iteration cycles
* Angry users, churn, and bad reviews

NoteX fixes this by turning raw feedback into **structured, actionable intelligence** — instantly.

---

## ✨ Core Features

### 🔴 Real-Time Feedback Stream

* Live feedback ingestion powered by Supabase Realtime
* See issues, ideas, and complaints as they happen

### 🤖 AI-Powered Analysis

* Automatic feedback summaries
* Advanced sentiment & tone detection
* Smart grouping of similar feedback using AI
* Suggested replies and insights

### 🎨 Customizable Feedback Widget

* Brand colors, logo, and greeting text
* Plug-and-play embed script
* Seamless website integration

### 📊 Analytics Dashboard

* Feedback trends & sentiment overview
* Actionable metrics for product decisions
* Export reports (PDF / CSV)

### 🔔 Notifications

* Instant email alerts for new or critical feedback
* Configurable notification preferences

### 💳 Billing & Access Control

* Paystack subscription billing
* 8-day free trial with automatic lock
* Upgrade, cancel, and card management
* Role-based access for teams
