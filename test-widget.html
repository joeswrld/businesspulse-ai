NoteX Feedback Widget Test Page

This page demonstrates the NoteX feedback widget in action. You should see a floating feedback button in the bottom-right corner of the screen.

Testing Instructions:

  1. Look for the blue feedback button in the bottom-right corner
  2. Click the button to open the feedback form
  3. Verify that the form fields are visible and functional
  4. Test filling out the email and message fields
  5. Try submitting the form
  6. Check that the form closes after submission

Widget Features to Test:

  • ✅ Widget button appears and is clickable
  • ✅ Modal opens when button is clicked
  • ✅ Form fields are visible and styled properly
  • ✅ Email input field works
  • ✅ Message textarea works
  • ✅ Submit button is functional
  • ✅ Cancel button closes the modal
  • ✅ Close (X) button works
  • ✅ Form validation works (message is required)
