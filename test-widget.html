🚨 Common Issues & Solutions

If you see "⚠️ Something went wrong":

  • Check browser console for detailed error messages
  • Verify the API endpoint is deployed: supabase functions deploy feedback-api
  • Check function logs: supabase functions logs feedback-api
  • Ensure database tables exist: Run setup-feedback-system.sql
  • Verify the project ID is valid in your NoteX dashboard

✅ Success Indicators

  • Widget button appears in bottom-right corner
  • Form opens when button is clicked
  • Console shows "NoteX Feedback Widget: Submitting feedback"
  • Success message appears after submission
  • Feedback appears in your NoteX dashboard
